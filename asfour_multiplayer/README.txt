حروف مع عائلة العصفور — نسخة أونلاين

هذه النسخة تتطلب استضافة Node.js تدعم WebSocket (مثل خدمة ويب على Render أو Railway أو Replit).
لا تعمل مزامنة الغرف عند رفع الملفات وحدها إلى Netlify Drop لأنه يستضيف ملفات ثابتة فقط.

التشغيل على الكمبيوتر:
1. ثبّت Node.js إصدار 18 أو أحدث.
2. افتح مجلد المشروع في الطرفية.
3. نفذ npm install ثم npm start.
4. افتح http://localhost:3000

للنشر: ارفع المشروع إلى استضافة Node.js، واجعل أمر التشغيل npm start. بعدها استخدم الرابط الذي توفره الاستضافة.
الغرف محفوظة في ذاكرة الخادم، وتختفي عند إعادة تشغيله. المضيف يتحكم باللعبة، والبقية يشاهدون التحديثات لحظيًا.
